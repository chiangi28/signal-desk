Install and connect

Get Signal Desk running

The Skill works on its own. Add Notey when you want a desktop face, quick checks, and easier handoff to WorkBuddy.

  1. Install WorkBuddy

    Use the official WorkBuddy desktop app. This site does not redistribute WorkBuddy.

  2. Import Signal Desk Skill

    Download the Skill zip, then use WorkBuddy's import / add skill pack flow.

  3. Install Notey on Windows

    Download the Notey zip, extract it, and run the installer or Run-Notey.bat.

  4. Trust mcp.pet

    In Notey, use Connect WorkBuddy / copy setup, then trust mcp.pet inside WorkBuddy. The site cannot skip that click.

  5. Check and first knock

    Run Check / ping. Start with the fixture flow; live inbox binding is separate.

Honest boundaries

Signal Desk is a WorkBuddy skill. Notey is only the assistant desktop pet.

Demo fixture data is not live WeCom, Slack, or email data.

This is not a medical device, hotline, diagnosis tool, or emergency service.

Skill-only mode is valid: you can skip Notey and still use the skill in WorkBuddy.
